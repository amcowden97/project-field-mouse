# Project Field Mouse

Project Field Mouse is a lightweight, local-first wildlife acoustic monitoring station
for Raspberry Pi. It records audio, analyzes it with BirdNET, stores detections in
SQLite, and presents activity and station health in a Flask dashboard.

Start with the [installation guide](docs/INSTALLATION.md). See also the
[architecture](docs/ARCHITECTURE.md), [operations guide](docs/OPERATIONS.md),
[repository audit](docs/AUDIT.md), and [roadmap](docs/ROADMAP.md).

For hardware-free development, follow the [developer quick start](docs/DEVELOPMENT.md)
and [simulator guide](docs/SIMULATOR.md). Routine station tasks are documented in the
[CLI reference](docs/CLI.md).

The current release candidate is `3.0.0-rc1`. Before deploying it, review
[the release notes](RELEASE_NOTES.md) and complete the
[release checklist](docs/RELEASE_CHECKLIST.md).
